
# COVID-19 Tableau Dashboard

An interactive Tableau dashboard that analyzes COVID-19 trends using real-world data.

## Project Overview

This project explores COVID-19 data through interactive visualizations to help understand infection trends, deaths, recoveries, and regional comparisons.

## Tools Used

- Tableau
- Data Visualization
- Dashboard Design

## Features

- Global COVID-19 trend analysis
- Country-wise comparison
- Interactive filters
- Clear and easy-to-understand visualizations
